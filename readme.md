# 🎮 TrioWorld

**TrioWorld** is a challenging 2D vertical platformer built with **Godot 4**, inspired by Foddian-style games. Master charge-based jumping, navigate tricky platforms, and race to reach the top!

## 🕹️ Features
- Charge-based jumping and wall-bouncing mechanics
- Challenging vertical platforming gameplay
- Global leaderboard powered by PlayFab
- Completion time tracking
- Mobile-friendly touch controls
- English and Khmer language support
- Browser and Telegram Mini App support

## 🛠️ Tech Stack
**Godot 4** • **GDScript** • **PlayFab** • **Telegram Mini Apps**
